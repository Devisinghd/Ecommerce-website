# Project Summary for GitHub / Resume

This is a Django-based e-commerce backend built for real-world online shopping workflows, including product management, authentication, cart handling, checkout, order tracking, and API documentation.

The project demonstrates secure JWT-based authentication, seller-side product management, customer order flows, address handling, PostgreSQL-ready architecture, and deployment-friendly configuration for containerized hosting platforms.

It was designed as a practical portfolio project to showcase backend engineering, API design, and production-oriented system thinking.

## Short profile description

Django e-commerce backend with JWT auth, cart/checkout logic, seller product management, order processing, and API documentation.

## Resume-friendly version
